# 🗺️ 催事場所検索ツール

住所と半径を指定してCSVデータから近隣の催事会場を検索し、予約サイトの空き状況も確認できるWebアプリです。

---

## 必要要件

- Python 3.10 以上
- pip

---

## セットアップ手順

### 1. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. Playwright（Chromium）のインストール

```bash
playwright install chromium
```

### 3. CSVデータの配置

`data/` フォルダに以下の10ファイルを配置してください：

```
data/
├── 催事場所リスト - 東京.csv
├── 催事場所リスト - 埼玉.csv
├── 催事場所リスト - 神奈川.csv
├── 催事場所リスト - 千葉.csv
├── 催事場所リスト - 茨城.csv
├── 催事場所リスト - 栃木.csv
├── 催事場所リスト - 群馬.csv
├── 催事場所リスト - 山梨.csv
├── 催事場所リスト - 長野.csv
└── 催事場所リスト - 新潟.csv
```

### 4. アプリの起動

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。

## 使い方

### STEP 1：住所 × 半径で会場を検索

1. 「検索する住所を入力」欄に基点となる住所を入力します
   - 例: `東京都渋谷区渋谷1-1-1`
2. 「半径を選択」で検索範囲を選びます（3 / 5 / 10 / 20 / 25 km）
3. 「会場を検索」ボタンをクリックします

> **初回のみ**、全会場住所のジオコーディング（住所 → 緯度経度変換）が実行されます。
> 会場数が多い場合、Nominatim の制限（1リクエスト/秒）により数分かかることがあります。
> 2回目以降はキャッシュから読み込むため高速です。

検索結果は一覧表示され、CSV・Excel でダウンロードできます。

---

### STEP 2：期間を指定して空き状況を確認

STEP 1 で会場が見つかった後に表示されます。

1. 開始日・終了日を選択します
2. 「空き状況を確認する」ボタンをクリックします
3. 各予約サイトに自動でログインして空き状況を確認します

結果は以下の3区分で表示されます：

| 区分 | 説明 |
|------|------|
| ✅ 空きあり | 対応サイトで期間内すべて空きと確認できた会場 |
| ⚠️ 確認不可（手動確認要） | グラスト等の未対応サイト、またはログインエラーが発生した会場 |
| ❌ 予約済みで除外 | 1日以上予約済みと確認された会場 |

## 注意事項

- **ジオコーディング**: Nominatim（OpenStreetMap）の無料APIを使用しています。大量リクエスト時は制限に引っかかる場合があります。
- **Playwright**: 各予約サイトの HTML 構造変更に伴い、空き確認ロジックの調整が必要になる場合があります。
- **認証情報**: IDとパスワードはコード内（`availability.py`）にハードコードされています。セキュリティが必要な場合は `.env` ファイルへの移行を検討してください。
