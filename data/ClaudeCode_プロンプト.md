## アプリ概要
催事場所検索ツール。住所を入力して半径範囲を指定すると、CSVデータから該当する会場をピックアップし、さらに指定期間で各予約サイトの空き状況を確認して絞り込みができるツール。

- 催事場所リスト_-_長野.csv
- 催事場所リスト_-_新潟.csv

### CSVフォーマット
- 1行目: 都道府県名（1列目のみ）
- 2行目: ヘッダー行（2列目から始まる）
  - 列順: 施設名, 実施場所名, 施設住所, 広さ, 屋内・屋外, 発注先, 金額（平日）, 金額（土日祝日）, 通信催事可否, 机貸出, 椅子貸出, 電源貸出, 注意事項, AGでの手配実績, ...
- 3行目以降: データ行（2列目から始まる、1列目は空）
- 読み込み時は2行目をヘッダーとして使用し、空行・ヘッダーのみの行はスキップする
- encoding は `utf-8-sig` を使用

## 機能仕様

### STEP 1: 住所入力 × 半径検索

**UI要素：**
- テキスト入力: 「検索する住所を入力」（例: 東京都渋谷区渋谷1-1-1）
- セレクトボックス: 半径選択（3km / 5km / 10km / 20km / 25km）
- ボタン: 「会場を検索」

**処理：**
1. 入力住所を `geopy` の `Nominatim` でジオコーディングして緯度経度を取得
2. 各CSVの「施設住所」列も同様にジオコーディング（初回のみ実行し `st.session_state` にキャッシュ）
3. `geopy.distance.geodesic` で距離計算
4. 指定半径以内の会場を抽出

**表示列（ピックアップ項目）：**
- 施設名
- 実施場所名
- 施設住所（CSVの「施設住所」列）
- 広さ
- 屋内・屋外
- 金額（平日）
- 金額（土日祝日）
- 通信催事可否
- 発注先（内部処理用。表示はするが、空き確認サイト判定にも使用）

**結果表示：**
- 件数を表示
- DataFrameで一覧表示（st.dataframe）
- 「CSVダウンロード」ボタン → `st.download_button` でCSV出力
- 「Excelダウンロード」ボタン → `openpyxl` を使いExcel（.xlsx）出力。`st.download_button` でダウンロード

---

### STEP 2: 期間指定 × 空き状況確認

STEP1で会場が抽出された後に表示される。

**UI要素：**
- 日付入力: 開始日・終了日（`st.date_input`）
- ボタン: 「空き状況を確認する」

**処理概要：**
Playwright（`playwright`パッケージ）を使い、各会場の「発注先」列に対応するサイトにログインして空き状況を確認する。

**発注先 → サイトのマッピング：**
発注先の文字列には複数サイトが「／」で区切られる場合がある（例: 「グラスト／場所とる」）。
その場合は記載されているすべてのサイトを確認する。
また「グラスと」（typoあり）も「グラスト」と同一とみなす。

以下のサイトを使用（認証情報はコード内にハードコード）：

| 発注先キーワード | サイト名 | URL | ID | PW |
|---|---|---|---|---|
| 場所とる / 場所取る | 場所とる | https://bashotoru.com/ | ba1@agent-network.com | Agent0416T |
| スペースラボ | スペースラボ | https://spacelab-system.jp/ | shun.sato@agent-network.com | Agent0401 |
| 楽市 | 楽市 | https://rakuichi-space.com/login | shun.sato@agent-network.com | Fz8sWeuB |
| 自由市場 | 自由市場 | https://www.jiyu18.jp/mypage/members/login | ba2@agent-network.com | agent0416 |
| ダイエースペース | ダイエースペース | https://web-space.daiei-spacecreate.com/ | 300118 | Passw0rd |
| グラスト / グラスと / アイフィールド / ライフ / ネクサスイノベーション | （非対応サイト） | - | - | - |

※ 「グラスト」「アイフィールド」「ライフ」「ネクサスイノベーション」は対応サイトなし。これらのみの会場は「確認不可（手動確認要）」として扱い、リストに残す。

**各サイトの空き確認ロジック：**

各サイトにPlaywrightでログインし、施設名（実施場所名）で検索して、指定期間（開始日〜終了日）のすべての日付が空いているかを確認する。
「1日でも予約済みならその会場を除外」とする。

サイトごとのログイン・検索の実装は、実際のサイトのHTML構造をPlaywrightで確認してから実装すること。
各サイトへのアクセスは `async` で行い、並列処理（asyncio）で高速化する。
Playwright は `chromium` を `headless=True` で起動する。

**処理中の表示：**
- `st.spinner("空き状況を確認中...")`
- 各サイトごとに進捗を `st.write` で表示

**結果表示：**
- 「空きあり」と判定された会場のみDataFrameで表示
- 「確認不可（手動確認要）」の会場は別セクションで表示
- 各会場に「確認サイト」「確認結果」列を追加
- STEP1同様にCSV・Excelダウンロードボタンを表示

## 追加実装要件

- ジオコーディングは `Nominatim(user_agent="saiji_search")` を使用
- 住所のジオコーディング失敗時は該当会場をスキップし、スキップした件数を警告表示
- Streamlit の `st.session_state` でジオコーディング結果・検索結果をキャッシュし、再計算を防ぐ
- エラーハンドリング: 各サイトへのアクセス失敗時は「確認エラー」として表示しリストに残す
- UIは日本語で統一

## 使い方

1. 上記プロンプトをコピーしてClaude Codeに貼り付ける
2. CSVファイルを `data/` フォルダに配置するよう指示される
3. `pip install -r requirements.txt` と `playwright install chromium` を実行
4. `streamlit run app.py` でアプリ起動

## 注意事項

- 各予約サイトのHTML構造は定期的に変わる可能性があるため、Playwright部分は実際のサイトにアクセスして都度確認・修正が必要な場合があります
- ジオコーディング（Nominatim）は無料APIのため、リクエスト制限があります。大量の会場データを初回読み込む際に時間がかかることがあります
- 認証情報（ID/PW）はコード内にハードコードされます。セキュリティが必要な場合は `.env` ファイルへの移行を検討してください
